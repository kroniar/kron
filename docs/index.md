# 🌀 Kron Documentation

Welcome to the official documentation for **Kron** —  
the open automation framework for DevOps and SREs.

---

## ✨ Overview

Kron is a modular CLI written in Go, built with [Cobra](https://github.com/spf13/cobra).  
It provides a pluggable structure to add automation commands like:

- Managing YAML/JSON configurations
- Automating GitHub/GitLab PRs
- Spinning up local observability stacks (Prometheus, Grafana)
- Managing infrastructure from the command line

---

## 🧩 Getting Started

'''bash
git clone https://github.com/kroniar/kron.git
cd kron
go run main.go
'''
